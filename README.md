# Indian State Patents and Economic Growth

This project examines the relationship between patent activity, economic growth, electricity consumption, and nighttime lights across 27 Indian states over fiscal years 2013–14 to 2024–25.

## Research Questions

1. Is patent activity associated with subsequent growth in nighttime lights?
2. Is patent activity associated with subsequent growth in real GSDP per capita?
3. Is patent activity associated with subsequent growth in per-capita electricity consumption?
4. Is prior economic growth associated with subsequent patent activity?

## Methodology

The analysis uses state-year panel data and fixed-effects regressions with state and year fixed effects. Standard errors are clustered by state.

The results are observational and are not interpreted as causal effects.

## Repository Structure

- `data/` — Data documentation and information on data sources.
- `code/` — Stata scripts for data preparation and econometric analysis.
- `results/` — Documentation of regression results and planned outputs.

## Reproducibility

The project aims to document data preparation, variable construction, sample restrictions, model specifications, and statistical software requirements so that the analysis can be reproduced.

Raw datasets are not included by default. Data sources and access conditions will be documented separately.

# Code

This directory contains the Stata scripts used for data preparation and econometric analysis.

## Planned Scripts

- `01_prepare_data.do` — Import data, align fiscal years, construct variables, and declare the state-year panel.
- `02_baseline_regressions.do` — Estimate fixed-effects regressions for nighttime lights, GSDP per capita, and electricity consumption.
- `03_reverse_direction.do` — Examine whether previous economic growth is associated with subsequent patent activity.

## Reproducibility

Scripts will document variable construction, sample restrictions, model specifications, and required Stata packages.

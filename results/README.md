# Results

This directory contains the regression tables generated by the Stata scripts.

## Expected outputs

- `patent_regressions.tex` — Baseline regressions examining the relationship between lagged patent activity and nighttime-light growth, real GSDP per-capita growth, and electricity consumption growth.
- `reverse_direction_results.tex` — Reverse-direction regressions examining the relationship between prior economic growth and subsequent patent activity.

## Reproduction

Run the scripts in the `code/` directory in the order specified in `code/README.md`. The regression tables will be generated in this directory.

Generated regression tables are not committed by default. They can be reproduced from the source data and the Stata scripts.

**Note:** These outputs report conditional associations and should not be interpreted as causal estimates.

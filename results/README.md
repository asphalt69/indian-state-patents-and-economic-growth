# Results

This directory contains regression tables and figures generated by the analysis.

## Baseline Regressions

The baseline models examine the association between lagged patent activity and:
- Growth in nighttime lights
- Growth in real GSDP per capita
- Growth in per-capita electricity consumption

All baseline models include state and year fixed effects, with standard errors clustered by state.

## Reverse-Direction Analysis

Additional models examine whether previous economic growth is associated with subsequent patent activity.

## Interpretation

The results are observational and should not be interpreted as causal effects.

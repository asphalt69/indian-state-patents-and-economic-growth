# Data Documentation

This directory documents the datasets used in the Indian state-level patents and economic growth project.

## Data Sources

The analysis combines state-level data on:
- Patent applications
- Real GSDP per capita
- Per-capita electricity consumption
- VIIRS nighttime lights

## Data Preparation

The working panel covers 27 Indian states over fiscal years 2013–14 to 2024–25.

Fiscal-year observations are aligned with VIIRS calendar-year observations. Variable definitions, transformations, missing-data treatment, and sample restrictions will be documented alongside the analysis code.

## Data Availability

Raw datasets are not included in this repository by default. Data sources and instructions for obtaining the data will be documented here. Redistribution will depend on the applicable data-use terms.
